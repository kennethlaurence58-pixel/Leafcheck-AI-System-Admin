# LeafCheck AI – UI Prototype

This package contains the Expo React Native user and administrator interfaces only. Backend, Prisma, database, server, Supabase, and firmware files have been removed.

## Run

```bash
npm install
npx expo start -c
```

The existing user UI and the interactive admin UI (Dashboard, Users, Devices, APIs, and Settings) are preserved. Admin actions currently operate as frontend prototype interactions/modals and are ready to connect to a backend later.
